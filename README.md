# GRASS GIS Scripts — Cartographic Projections and Raster Analysis Techniques

A general reference collection of GRASS GIS shell scripts by Polina Lemenkova, demonstrating cartographic and raster-analysis techniques on sample ETOPO1 raster data. Not tied to a specific publication.

## Contents
- **Cartographic projections:** Oblique Mercator, Cassini, Equal-Area Conic and Two-Point Equidistant Azimuthal.
- **Raster analysis:** contour/isoline generation (r.contour), slope and aspect (r.slope.aspect), fractal surface generation (r.surf.fractal), univariate statistics (r.univar), and map algebra with raster masking (r.mapcalc, MASK).
- **Display:** multi-panel faceted plots (d.frame) with cartographic grids, legends and text annotations (d.rast, d.vect, d.grid, d.legend, d.text).

## Usage
Each script is standalone and reproduces one technique. Adapt the input raster names and region to your own data.
